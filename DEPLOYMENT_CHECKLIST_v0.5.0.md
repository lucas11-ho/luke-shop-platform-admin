# Deployment Checklist — Platform Admin v0.5.0

Prerequisite: Backend v0.12.0 and migration 013.

- Deploy the existing Cloudflare project for `luke-shop-platform-admin`.
- Open Template & Font Studio → Status visuals.
- Confirm all platform packs load.
- Edit one non-critical icon mapping and save.
- Confirm the corresponding storefront receives the resolved mapping after refresh/publish as applicable.
- Confirm semantic fulfillment status values are unchanged.

# Luke Shop Platform Admin v0.2.1 — Professional Control Center UX Polish

Adds client-side audit search/action/client/date filters, pagination, expandable event detail, clearer Platform Owner identity treatment, and stronger keyboard focus states. No API or database changes.

## Compatibility

- Backend: v0.8.0 unchanged
- Database migrations: unchanged through 009
- Tenant routing/auth/permissions: unchanged
- Existing `.env` and `package-lock.json` must be preserved by the upgrade installer.

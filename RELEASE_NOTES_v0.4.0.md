# Luke Shop Platform Admin v0.4.0 — Platform Control Completion

This release expands Platform Admin from tenant provisioning/design-catalog inspection into a practical SaaS control plane.

## Added or completed

- Plan create/edit controls.
- Typography preset create/edit controls.
- Tenant store create/edit controls.
- Tenant currency, locale, timezone and internal notes.
- Tenant-owner display name, email and access-state management.
- Tenant-owner password reset and force logout preserved.
- Real DNS TXT challenge display/check flow and domain removal.
- Platform Owner own profile/password/session management.

Manual domain verification is removed from the control surface.
